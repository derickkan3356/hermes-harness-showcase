# Frontend — Open WebUI on laptop and phone, scheduled posts you can follow up

One user, two devices: laptop and Android phone, both on the tailnet. Needs: chat with new session, edit message, regenerate; scheduled prompts whose result lands in a chat that can be followed up in place.

Shape: Open WebUI (installed with `uv`, runs in WSL) talks to the Hermes gateway's OpenAI-compatible API server (`gateway/platforms/api_server.py`, env `API_SERVER_ENABLED` / `API_SERVER_HOST` / `API_SERVER_PORT` / `API_SERVER_KEY`) on `127.0.0.1:8642`. Scheduled posts are Open WebUI **Automations**: each run opens an ordinary chat with Hermes as the model. Only Open WebUI is exposed on the tailnet, behind Tailscale Serve (HTTPS, needed for the Android home-screen app).

Hermes cron is not used for these posts — one scheduler, one place to look.
