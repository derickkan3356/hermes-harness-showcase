# AI news digest — daily HKT 07:00, Traditional Chinese, feeds as the source, repeats blocked in code

The first real use case. Once a day, the current period's AI news is gathered into one Traditional Chinese post that appears as a new Open WebUI chat. Source language does not matter; the output is 書面語 with technical terms in English (`docs/ai-news.md`, Language).

How each part works, and why: `docs/ai-news.md`.
